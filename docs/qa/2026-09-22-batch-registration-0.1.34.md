# 0.1.34 批次登记修复与真实重生成

## 范围与原因

用户授权修复后重新生成项目 222 的 5 条成片。原错误发生在所有成片已编码之后：第四条内部 ID 包含中文，规划阶段只检查非空/唯一，登记阶段的 ASCII 合同拒绝整批。通用 422 隐藏了具体字段。

## 修改

- 共享内部编号合同，非法模型标签转换为稳定、安全的服务端编号；新文件名拒绝 Windows 设备名，计划检查大小写碰撞。
- 方案保存和渲染前校验标题/片段/编号等限制；最终 Manifest 预检发生在 FFmpeg 之前。
- 每次重新规划使用新的输出代号，保留以前的所有成片。
- 全部渲染完成后保存登记检查点及 SHA-256；重试登记不再调用模型、ASR 或编码。
- 恢复导入保持声学逐字时间，已存在的人工字幕稿及历史不覆盖。
- 任务 lease、revision、generation 防止取消后迟到的工作器覆盖新任务；恢复队列会处理已保存方案。
- UI 区分“重新尝试”和“重试登记”，错误提示具体到成片和字段。
