## 行为

- 允许保存草稿，但入队前检查所有原片可读取、非空，且至少一条原片达到最短成片时长。失败不修改项目、revision 或历史事件。
- 每条成片只使用一个原片，不同成片允许复用选段。因此不能把多个短原片时长相加，也不能用“数量乘以最短时长”误拦合法项目。
- 同一检查也在队列领取后、调用规划器前执行，覆盖等待期间文件失效和中断恢复。已提交渲染与登记恢复不进入新规划检查。
- 列表/详情返回临时 `generation_check`，不改数据库；UI 禁用开始/重试按钮并显示阻塞原因。接口自身仍在事务内检查，不能绕过 UI 入队。
- 保留全量方案数量、来源、选段范围、重叠、时长和冻结 Skill 校验。时长错误增加候选顺序、实际值、范围和差值，毫秒精度，不放宽限制，不强行截断口播。
- 失败说明直接可见，同时保留技术详情。旧错误仅按其已保存信息解释，不捏造当时未保存的数值。
- 不增加自动模型重试。前置检查无模型费用；方案校验在模型返回后执行，该次模型调用可能已经计费。检查通过不等于模型质量保证。
- UI 保留渐变工作台；按 Impeccable 的错误恢复规则使用现有样式和可读原因，不重新设计布局。派生禁用状态不另存副本，避免轮询状态漂移。
