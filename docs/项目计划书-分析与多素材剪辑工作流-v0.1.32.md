## 2. 实际流程与位置

| 用户任务 | 当前入口与行为 | 保护边界 |
| --- | --- | --- |
| 分析对标视频 | 素材分析上方多选/拖放视频，确认加入本机处理队列，再进入深度分析与 Skill 审核 | 上传视频不是自动批准方法；原片处理与云端深度分析仍分阶段 |
| 导入 Codex 方法 | 下方导入 .cfskills 或包含一个 .cfskills 的 ZIP，预览后确认加入 | 不执行包内脚本，不覆盖本机编辑或停用的方法；本格式没有视频实体 |
| 查看可用方法 | 上传区下方显示批准且可复用的方法名称、版本和机制；保留原审核组件 | “学习”指读取已审核方法快照，不是重新训练大模型 |
| 新建剪辑项目 | 视频剪辑 → 新建项目；左素材、右名称/款号/参数 | 最多 20 条原片；款号可空，不由模型猜测 |
| 保存和启动 | 保存后进入左侧列表；选择项目，点击“开始剪辑”才进入队列 | 保存不启动付费模型调用；项目独立，可继续建立其他项目 |
| 多风格成片 | 每条候选保存 skill_id 和完整版本快照 | 每项目 1–20 条成片；允许复用，不强求不适合的不同风格 |
| 查看项目结果 | 右侧逐条展示方法、来源和选段；“查看本批成片”定位批次 | 每条输出仍来自一条原片的多个有序片段，尚不跨原文件拼接 |
| 成片整理下载 | 按款号筛选批次文件夹，批次内预览、审核、单条或 ZIP 下载 | 待审核与通过分开，不将待审核标为合格投放素材 |
| 删除项目 | 非运行项目移入回收站；永久删除前显示清单 | 外部原文件、其他项目或成片/字幕引用的文件保留 |

## 3. UI 规范和取舍

- 延续浅色、低装饰、玫红主操作风格，不改成营销页，不更换技术框架。
- 沿用 Noto Sans SC 及字号变量；项目标题 26px、区域标题约 20px、按钮/表单约 16px、辅助信息 14–15px。
- 取消顶部“舒适/大字号”按钮；已有字号偏好不强行清除。
- 取消剪辑页大段步骤说明，改成紧凑标题与工具栏。
- 大窗口左项目列表、右详情分别滚动；小窗口纵向重排。
- 新建项目双栏，上传列表有首帧预览、文件名、大小、上移/下移/移除。
- 保留模型连接、更新、人工字幕校对、审核、下载能力。

本次没有新增项目搜索、项目重命名界面、状态筛选或单条成片组合多个 Skill 的规则；早期设想不作为“已完成”项目。

## 4. 物理删除规则

1. 仅能删除已在回收站且不运行的项目。
2. 预览会删除、保留、缺失的文件，以及保留原因。
3. 确认绑定项目 revision 和清单令牌；文件或引用变化时重新确认。
4. 仅删除 sources/<32位标识>/<视频> 中的普通单链接文件，不递归删目录。
5. 外部原文件、符号链接/Junction/硬链接、不明路径、其他项目/成片/字幕/剪辑工程引用的文件保留。
6. 先持久化删除意图再操作文件。失败留在回收站供重新预览、重试；已部分删除时不得伪装成完整可恢复项目。
7. 成片、字幕、分析缓存、审计和历史事件不随项目物理删除，不能声称这些空间已释放。

物理删除不能从软件回收站恢复。本轮仅删除验收脚本生成的测试文件，没有删除用户真实素材。

## 5. Skill 包协议和边界

- 支持已有 schema:1 的 .cfskills，保存批准后的方法、版本和文字证据快照。单包最大 32 MiB、最多 1000 个方法，ZIP 仅作为此文件容器。
- 一个包可含多个方法；“预览 → 确认 → 原子写入”，重复导入不覆盖。
- 普通 SKILL.md、任意目录 ZIP、仅改名为 Skill 的视频，不自动转成结构化方法。
- 包中没有可播放原片；原视频需在对标视频入口上传。本轮未实现“视频实体＋任意 Markdown 一体包”的迁移协议。
- 没有平台内部数据时，不把内容相关性表述为算法因果。

## 6. 实施顺序和验收

1. 参数/合同：款号、20 数量上限、逐条 Skill 快照；兼容旧项目。
2. 安全删除：引用保护、预览令牌、二次确认、失败重试、迟到 worker 防护。
3. 页面：对标多选、Skill 包入口、项目列表/详情、批次定位与款号分类。
4. 浏览器验收：失败保留、重开、恢复/永久删除、包导入、真实 ZIP 内容与布局。
5. 后端回归：多 Skill 计划及真实 FFmpeg 输出；前端类型与行为检查。
6. 实开隔离 Tauri 窗口。正式安装包另行交付，不将测试 EXE 当作独立安装程序。

测试证据与未验证项见 qa/2026-09-21-workflow-0.1.32.md。
